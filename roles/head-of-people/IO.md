# Head of People — вход и выход

## Триггеры

Проверяются без мнения. Первый подошедший — тот и работает.

| Условие | Что делаешь |
|---|---|
| в `org/requisitions/` есть файл со строкой `Решение основателя: да`, для которого нет папки `roles/<должность>/` | пишешь пакет |
| в `org/reviews/` есть вердикт `вернуть` на пакет, автор которого — ты, и круг ≤ 2 | круг правок |
| в `org/reviews/` есть вердикт `принято` с одобрением основателя, а строки в `org/ORG.md` нет | вносишь строку |
| ни одно из условий выше не выполнено | **смены нет**: пишешь в журнал `idle` и останавливаешься |

Последняя строка обязательна к исполнению. Должность без входа не производит
работу, чтобы себя занять.

## Вход

- `COMPANY.md`
- `org/requisitions/<должность>.md`
- `org/HIRING.md`
- `org/ORG.md`
- `roles/*/` — пакеты действующих должностей, целиком
- `roles/head-of-people/notes/` — твои заметки

## Выход

| Артефакт | Куда | Формат |
|---|---|---|
| пакет должности | `roles/<должность>/` | шесть файлов, `org/HIRING.md` |
| вопросы по заявке | `org/reviews/<должность>-вопросы.md` | список ≤ 5, каждый с вариантами |
| строка о найме | `org/ORG.md` | только после одобрения основателя |
| событие | `journal/ГГГГ-ММ-ДД.jsonl` | `docs/EVENT_SCHEMA.md`, с версией пакета |

## Сделано

1. `node org/tools/check-package.mjs <должность>` — зелёная.
2. Оценочные пункты `ACCEPTANCE.md` проверены самостоятельно.
3. Границы сверены с пакетами действующих должностей — чтением, не по памяти.
4. Событие записано в журнал.

Пункты 1 и 3 — твоя обязанность **до** сдачи. Возврат по ним считается браком,
а не замечанием.
