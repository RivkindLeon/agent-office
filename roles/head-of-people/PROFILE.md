# Head of People — квалификация

**Версия пакета: 6.0**

Версия поднимается по правилу из `org/HIRING.md`: старшая — когда меняются
обязанности, границы, критерии приёмки, грейд или модель; младшая — когда
уточняются формулировки. Версия пишется в каждое событие журнала.

## Грейд

**Middle.** Работа не требует ни глубокого предмета, ни сложных решений, но
требует аккуратности и точных формулировок, а цена ошибки высокая: плохо
описанная должность тиражируется на всех, кого она потом опишет.

## Требования

| Требование | Нужно | Почему |
|---|---|---|
| зрение | нет | работает только с текстом |
| длинный контекст | да | читает пакеты всех действующих должностей целиком |
| следование формату | да | шесть файлов с обязательными разделами |
| знание предмета | нет | и прямо запрещено судить о предмете |

## Модель и права

| | |
|---|---|
| Основная модель | `openai/gpt-5.6-luna` |
| Фолбэк | `openai/gpt-5.5` |
| Профиль инструментов | `coding` |
| Рабочая папка | `~/projects/agent-office` |
| Выход за папку | закрыт (`tools.fs.workspaceOnly`) |
| Агент в OpenClaw | `head-of-people` |

Обе модели идут по подписке — расходуется квота, а не деньги. Основная совпадает
с моделью переводчика семьи, то есть окно квоты общее: при большом расходе
перевод уйдёт на свой фолбэк. Смена одна в сутки и текстовая, поэтому риск
принят основателем сознательно.

## Инструменты

Файлы своей рабочей папки и запуск `org/tools/*` — проверки процесса. Запись в
`COMPANY.md` и в чужие пакеты закрыта правилами пакета, выход за пределы папки —
конфигурацией. Сеть не нужна.

## Лимиты

| | |
|---|---|
| расход на смену | не больше 100 000 токенов |
| превышение | смена обрывается, в журнал `blocked` с причиной |

Лимит поднят со 40 000 после первого настоящего найма: на чтение всех
действующих пакетов плюс написание шести файлов сорока тысяч мало.

Лимит — ориентир для ревью, а не механизм: сегодня ничто в системе его не
обрывает.
