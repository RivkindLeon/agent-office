# Технический дизайн: Калькулятор

## Подход

Продукт строится как статическое одностраничное веб-приложение. Оно открывается
в современном браузере и не требует установки отдельного приложения или
серверной части. Арифметика отделена от управления интерфейсом: вычислительный
модуль принимает два конечных числа и одну из четырёх операций, а модуль
интерфейса читает ввод, вызывает вычисление и выводит результат в видимую область
страницы.

Допущение: продукт запускается в актуальном настольном браузере и получает два
числа и операцию через экранную форму, проверить при приёмке.

Входные значения преобразуются в числа до вызова вычислительного модуля. Деление
на ноль и нечисловой ввод не расширяют требования: тесты и реализация покрывают
только два конечных числа, а для деления — ненулевой знаменатель.

Допущение: стандартная точность чисел выбранного языка достаточна для
математически корректного результата в границах входных требований, проверить
при приёмке.

## Структура файлов

- `projects/calculator/package.json` — команды проекта и фиксированные версии
  инструментов разработки.
- `projects/calculator/index.html` — форма двух операндов, выбор операции, запуск
  расчёта и область результата.
- `projects/calculator/styles.css` — оформление страницы и видимое состояние
  результата.
- `projects/calculator/src/calculator.js` — чистая функция четырёх арифметических
  операций.
- `projects/calculator/src/app.js` — связывание формы, вычислительного модуля и
  области результата.
- `projects/calculator/tests/calculator.spec.js` — проверки математического
  результата для сложения, вычитания, умножения и деления по `REQ-001`.
- `projects/calculator/tests/result.spec.js` — браузерная проверка видимости
  результата после успешного расчёта по `REQ-002`.
- `projects/calculator/playwright.config.js` — запуск приложения и настройки
  браузерных тестов.

## Проверка

Тестовый раннер — Playwright Test. Он запускает локальную раздачу статических
файлов, открывает страницу в Chromium и проверяет продукт через пользовательский
интерфейс. Арифметические сценарии сравнивают показанный результат с ожидаемым
для каждой из четырёх операций; сценарий отображения отдельно подтверждает, что
после успешного расчёта результат виден пользователю.

Допущение: среда выполнения предоставляет Node.js 22 и Chromium, устанавливаемый
Playwright, проверить при приёмке.
