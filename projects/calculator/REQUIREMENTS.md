# Требования: Калькулятор

Допущение: базовые арифметические операции — сложение, вычитание, умножение и деление; при делении знаменатель не равен нулю, проверить при приёмке.

## REQ-001 — базовые арифметические расчёты

Продукт должен выполнять сложение, вычитание, умножение и деление для двух
конечных чисел и выдавать математически корректный результат; деление на ноль
не входит в требование.

Критерий приёмки: для каждой из четырёх операций с двумя конечными числами,
где при делении второе число не равно нулю, результат совпадает с математически
корректным результатом — да или нет.

## REQ-002 — отображение результата

После выполнения расчёта продукт должен показывать пользователю полученный
результат.

Критерий приёмки: после каждого успешно выполненного расчёта пользователь
может увидеть его результат — да или нет.
