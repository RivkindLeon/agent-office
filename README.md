# agent-office

Компания из агентов, которая растёт наймом и строит продукты.

Читать в этом порядке:

| Документ | О чём |
|---|---|
| [`COMPANY.md`](COMPANY.md) | хартия: чем занимается компания и как устроена |
| [`org/HIRING.md`](org/HIRING.md) | как появляется должность: пакет из шести файлов, версии, ревью |
| [`org/ORG.md`](org/ORG.md) | кто нанят на самом деле |
| [`docs/EVENT_SCHEMA.md`](docs/EVENT_SCHEMA.md) | формат журнала |
| [`docs/PRIOR-ART.md`](docs/PRIOR-ART.md) | чужой опыт: что взяли и чего не взяли |

## Дерево

```
COMPANY.md          хартия основателя
org/                структура, найм, заявки, вердикты
  tools/            проверки процесса: приёмка пакета, валидация журнала
roles/<должность>/  пакет: 6 файлов + notes/ — рабочее место сотрудника
journal/            события компании
docs/               схема журнала, прогресс, чужой опыт
work/               рабочие артефакты
```

Продукта в репозитории нет — его построит инженерная функция, когда её наймут.
Демка «Офиса», собранная основателем до найма, лежит вне репозитория:
`~/My/agent-office-prototype`.

## Команды

```bash
node org/tools/check-package.mjs head-of-people   # автоматическая часть приёмки
node org/tools/validate-journal.mjs               # журнал против схемы
```
